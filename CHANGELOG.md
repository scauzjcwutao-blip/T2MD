# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/),

## [0.1.0] - 2026-04-20

### Added
- 文本文件转 Markdown 的核心引擎 (`engine/`)
- 文档分类功能 (`classifier.py`)
- 语言检测功能 (`lang.py`)
- 转换流水线 (`pipeline.py`)
- CLI 命令行工具 (`t2md.py`)
- GUI 图形界面 (`t2md_gui.py`)
